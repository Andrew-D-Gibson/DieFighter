# Input prompts

Recovered, palette-matched Aseprite sources derived from the Kenney Input Prompts Pixel pack in `Assets/Inspiration Resources/Input Prompts Pixel/`. The source pack is CC0; see its License.txt. PlayStation symbols were drawn into the same button style.

Export with `python3 tools/export_art.py Art/Textures/UI/InputPrompts`. `tools/build_input_prompts.py` rebuilds these Aseprite sources from the source pack; edit sources here for subsequent artwork changes.
